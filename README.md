# pyeconomics

pyeconomics 1.0 is being rebuilt from the ground up as an open platform of
economics and finance models. They will be usable from Python, a command line,
a REST API, an MCP server and a web app. The plan, phase by phase, is in the
[project roadmap](https://github.com/pyeconomics-dev/pyeconomics/blob/main/docs/roadmap/ROADMAP.md).

So far, the repository holds only the 1.0 package skeleton: there is nothing to
use yet.

## Installing today

```sh
pip install pyeconomics
```

This installs **0.2.6**, the current stable release. It is MIT-licensed, and its
source and documentation live on the
[`legacy/0.2.x`](https://github.com/pyeconomics-dev/pyeconomics/tree/legacy/0.2.x)
branch and at <https://pyeconomics.readthedocs.io/>. 0.2.x receives security
fixes only, and reaches end of life when 1.0.0 is released. pip installs a 1.0
pre-release only when asked for one, with `--pre` or an exact version.
